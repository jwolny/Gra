# 💣 Bomberman – Java

A game inspired by the classic **Bomberman**, built using the **libGDX** framework in **Java**.

The player navigates a **randomly generated map**, destroys obstacles and enemies with bombs, and collects **power-ups** that increase their chances of victory.

---

## Key Features

- **Procedurally generated maps** – a different layout of obstacles every time you play.
- **Destructible walls** – many map elements can be blown up with bombs.
- **Power-up system:**
  - **Bomb range** – increase the explosion distance.
  - **Movement speed** – move faster across the map.
  - **Health** – take more damage before dying.
- **Explosions and collisions** – advanced collision system with an interactive environment.
- **Multiplayer mode** – support for multiple players.

---

## Technologies

- **Java**
- **libGDX** – 2D/3D game development framework in Java
- **Tiled Map Editor** – for managing level layouts
- **Gradle** – project build system
